MOTORES DE TRANSCRIPCIÓN
Whisper

Se ejecuta en tu equipo, sin clave ni internet. Necesita descargar un modelo una sola vez.

macOS

No requiere clave ni internet: usa el reconocimiento on-device de Apple. Necesita un idioma concreto — no puede autodetectar.

Azure

OpenAI

Transcripción en tiempo real por WebSocket. Tu API key se guarda cifrada en el keychain.

Grok

Transcripción en streaming. La API key vive solo en el proceso principal, nunca en la ventana de transcripción.

ElevenLabs

Scribe v2 Realtime (streaming). La API key vive solo en el proceso principal, nunca en la ventana de transcripción.

Reportar un error

Un reporte con detalles se resuelve mucho más rápido. Antes de abrirlo, revisa estos puntos.

QUÉ INCLUIR
  1. Qué esperabas y qué pasó en su lugar Describe primero el resultado que esperabas y luego lo que ocurrió. «No funciona» no permite reproducir nada.
  2. Pasos para reproducirlo Enumera lo que hiciste, en orden, desde que abriste la app. Indica si ocurre siempre o solo a veces.
  3. Capturas de pantalla Adjunta una imagen del problema. Si es algo que ocurre al dictar, un vídeo corto ayuda todavía más.
  4. Una captura de la pantalla «Acerca de» Incluye la versión, el sistema y las rutas. También puedes copiar esos datos como texto con el botón de abajo.
  5. El archivo de registro del día Adjunta el registro correspondiente a la fecha del fallo. Abajo encontrarás la carpeta donde se guardan.
  6. Tu motor de transcripción y su idioma Muchos errores dependen del proveedor: no es lo mismo Whisper local que Azure o ElevenLabs.
